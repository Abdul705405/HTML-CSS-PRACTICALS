## About This Repository

This repository contains the HTML and CSS practical assignments completed as part of the B.Tech Computer Science & Engineering curriculum at Invertis University. The exercises progress from version-control basics and introductory HTML elements to forms, tables, CSS fundamentals, Flexbox, Grid, and responsive page layouts.

The documentation and source references below reflect the files currently available in this repository. The practical output PDF currently verified in the repository is linked in Lab 01; PDFs mentioned in other lab notes were not found at their referenced paths during this review.

## Technologies and Tools

- **HTML5** – page structure and semantic elements used in the practicals.
- **CSS3** – styling, spacing, box model, Flexbox, Grid, and media queries.
- **Git and GitHub** – version-control and repository exercises in Labs 01–02.
- **Visual Studio Code** and a modern web browser – editing and viewing the practicals.

JavaScript is not included as a project technology: the inspected lab pages do not reference external JavaScript files or script elements.

## How to Run a Practical

These are static HTML/CSS exercises. No package installation or build process is required.

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Abdul705405/HTML-CSS-PRACTICALS.git
   ```

2. **Open the project folder:**

   ```bash
   cd HTML-CSS-PRACTICALS
   ```

3. Open the required `LabXX` folder in Visual Studio Code.
4. Open that lab's `index.html` file in a web browser. You can also use the VS Code Live Server extension if it is installed.
5. Edit the HTML file for page structure and the corresponding `style.css` file for presentation, then refresh the browser to view changes.

## Learning Outcomes

Across the practical sequence, the exercises provide practice with:

- Creating basic HTML documents and using headings, paragraphs, links, and images.
- Organizing information with ordered, unordered, and description lists.
- Building forms with common input and selection controls.
- Structuring tabular information with table sections and cell-spanning attributes.
- Applying CSS selectors, colors, typography, spacing, borders, and custom properties.
- Understanding the CSS box model and overflow.
- Arranging content with Flexbox and CSS Grid.
- Using media queries to adapt page layouts to different viewport sizes.
- Practising basic Git and GitHub repository operations.
